You are a senior full-stack engineer, UX architect, and AI application developer.

Build a complete, production-ready application named:

AI Creative Copy Agent

The application generates audience-specific marketing copy for Email, Mobile, and SMS using a multi-stage AI workflow.

Do not create only a visual prototype. Build a working full-stack application with a responsive React frontend, FastAPI backend, authentication, database persistence, AI integration, validation, testing, logging, and Docker support.

==================================================
1. PRIMARY OBJECTIVE
==================================================

Create an AI-powered application where authenticated users can:

1. Enter a raw marketing campaign brief.
2. Select a brand or product.
3. Select an output channel.
4. Select an audience segment.
5. Optionally select a language.
6. Generate personalized marketing content.
7. View the progress of each AI workflow stage.
8. Review structured Email, Mobile, and SMS outputs.
9. Copy, regenerate, and download generated content.
10. View previous generations and execution details.

The interface must look professional, modern, responsive, and suitable for an enterprise marketing platform.

12. MULTI-STAGE AI WORKFLOW
==================================================

Implement the workflow as modular services or agents.

Agent 1: Data Extraction

Input:

- Raw campaign brief

Responsibilities:

- Extract brand
- Extract product names
- Extract possible SKUs
- Extract athlete or public-figure references only when explicitly present
- Extract campaign goal
- Extract product features
- Extract campaign tone

Use a low-latency Gemini model.

Return validated structured JSON.

Agent 2: Web Search Grounding

Responsibilities:

- Search only when grounding is enabled.
- Search only relevant products, athletes, campaigns, or public information identified during extraction.
- Record sources separately.
- Never insert unsupported factual claims.
- If grounding is unavailable, continue using only the supplied campaign brief and clearly label the generation as not externally grounded.

Place the grounding provider behind an interface so it can be replaced.

Agent 3: Copy Generation

Input:

- Extracted data
- Grounding results
- Channel rules
- Audience profile
- Brand guidelines
- Previously generated copy for other audience segments
- Language
- Tone

Use a higher-quality Gemini model.

Return strict structured JSON matching the selected channel schema.

Agent 4: Repetition Fix

Responsibilities:

- Compare the new output with recent cached outputs.
- Detect repeated sentences, phrases, and excessive lexical similarity.
- Rewrite only when similarity exceeds a configurable threshold.
- Preserve the original campaign meaning.
- Do not rewrite the deterministic CTA.

Agent 5: CTA Optimization

Use deterministic business rules.

Examples:

- Product selected:
  "SHOP [PRODUCT NAME]"

- Brand selected:
  "EXPLORE [BRAND NAME]"

- No product or brand:
  "SHOP THE COLLECTION"

Store CTA rules in the database.

Agent 6: Output Parsing and Logging

Responsibilities:

- Validate final structured output using Pydantic.
- Record execution time.
- Record model names.
- Record individual agent status.
- Record recoverable errors.
- Store output in the database.
- Cache recent generations for repetition analysis.
- Never log passwords, access tokens, API keys, or sensitive request headers.
